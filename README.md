# Ollama Home Assistant Add-on Repository

This repository provides a Home Assistant Add-on for running [Ollama](https://ollama.com/) locally within your Home Assistant OS or supervised environment.

## Installation

1. In Home Assistant, navigate to **Settings** -> **Add-ons** -> **Add-on Store**.
2. Click the three dots in the top right corner and select **Repositories**.
3. Add the URL of this repository.
4. Close the dialog and search for "Ollama".
5. Install the add-on and wait for it to build/download.
6. Check the Add-on documentation for how to specify models to download.
